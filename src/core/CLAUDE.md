# Folder: src/core
> L2 | 父级: /CLAUDE.md

> 游戏核心逻辑层，包含 CSP 约束满足回溯求解器、连通色块生成器、关卡库及响应式状态机

## 成员清单
- `solver.ts`: 区域八皇后 CSP 回溯求解器、唯一解判定、8邻域冲突检测与智能提示算法
- `generator.ts`: 架构级几何多联块生成引擎（条带矩阵、拐角框与非对称大块），动态程序化生成保证唯一解谜题
- `hintEngine.ts`: 动态启发式逻辑推导提示引擎，基于当前棋盘状态进行错误诊断、行列区域锁定推导与快速应用
- `levels.ts`: 预置精选关卡库（包含原版截图第 24、26、33 关）与马卡龙调色板
- `state.ts`: 游戏核心状态管理器 (GameState)，处理落子、撤销栈、倒计时、生命值、动态提示与持久化

# Folder: src/ui
> L2 | 父级: /CLAUDE.md

> 用户界面与交互层，包含棋盘渲染引擎、手势触控系统、HUD状态栏与动画弹窗

## 成员清单
- `boardRenderer.ts`: 棋盘与色块渲染器，支持马卡龙多边形区域、小马/小牛SVG、色盲符号及冲突高亮
- `touchHandler.ts`: 移动端多点触控与手势识别器，支持单指点击循环、滑动连刷 ❌ 划叉与防误触
- `hudRenderer.ts`: 顶部资源栏、三公理规则胶囊牌、倒计时与底部道具栏渲染
- `modalRenderer.ts`: 通关胜利礼花特效、失败重试、设置菜单与支持 1~1000 关跳转选关弹窗
